# 📘 Project Documentation: RAG Chatbot API for AWS Security using Amazon Bedrock

## 🧠 Project Goal

To build a Retrieval-Augmented Generation (RAG) chatbot using **Amazon Bedrock** that answers questions based on documents about **AWS Cloud Security**. The chatbot is deployed locally as a **FastAPI** web server that exposes an API endpoint.

## 🛠️ Tools & Technologies

- **AWS Services:** Amazon S3, Amazon Bedrock, IAM, OpenSearch Serverless  
- **AI Model:** `meta.llama3-1-70b-instruct-v1:0`  
- **Embeddings Model:** `Amazon Titan Text Embeddings v2`  
- **Python Libraries:** FastAPI, boto3, uvicorn, python-dotenv  
- **Local Environment:** Python v3.11+, Git, AWS CLI, Virtual Environment

## ✅ Major Steps Completed

### 1. **Set up S3 Bucket**
- Created an S3 bucket `aws-security-rag-docs-[initials]` to store AWS security PDF documents.
- Uploaded content from *"Cloud Security: A Practical Guide to Security in the AWS Cloud"*.

### 2. **Create Bedrock Knowledge Base**
- Created a Knowledge Base using S3 as the data source.
- Selected `Amazon Titan Text Embeddings v2` as the embedding model.
- Used `OpenSearch Serverless` for the vector store.
- Synced the knowledge base successfully.

### 3. **Enabled Bedrock Models**
- Enabled access to:
  - `Titan Text Embeddings v2`
  - `meta.llama3-1-70b-instruct-v1:0`

### 4. **Configure AWS CLI**
- Installed AWS CLI locally.
- Created new **IAM access keys**.
- Configured the CLI using `aws configure`:
  ```
  AWS Access Key ID: [from .csv]
  AWS Secret Access Key: [from .csv]
  Default region: us-east-2
  ```

### 5. **Tested Bedrock CLI Chatbot**
- Ran `retrieve-and-generate` command using CLI to confirm Bedrock chatbot could answer:
  ```
  What is AWS Security?
  ```

### 6. **Cloned and Ran FastAPI Server**
- Cloned the GitHub repo: `https://github.com/NatNextWork1/nextwork-rag-api`
- Created and activated a virtual environment.
- Installed dependencies using `pip install -r requirements.txt`
- Created `.env` file with:
  ```
  AWS_REGION=us-east-2
  KNOWLEDGE_BASE_ID=2UXNKTNUUY
  MODEL_ARN=arn:aws:bedrock:us-east-2::foundation-model/meta.llama3-1-70b-instruct-v1:0
  ```

### 7. **Launched Local API**
- Ran the server:
  ```bash
  python -m uvicorn main:app --reload
  ```
- API was live at: `http://127.0.0.1:8000`
- Verified `/` endpoint
- Queried chatbot at:
  ```
  http://127.0.0.1:8000/bedrock/query?text=What%20is%20AWS%20IAM%20best%20practice
  ```

## 🧩 Challenges Faced & How We Solved Them

| 🔧 Issue | 😖 Description | ✅ Solution |
|--------|----------------|-------------|
| **"Unable to locate credentials"** | API returned this when querying `/bedrock/query` | Created IAM access keys and ran `aws configure` to set them locally |
| **Python not found** | Running `python3` failed | Switched to `python` command on Windows which correctly used the installed interpreter |
| **Missing environment variables** | API threw error due to undefined `KNOWLEDGE_BASE_ID` and `MODEL_ARN` | Created a `.env` file and added the correct values |
| **ModuleNotFoundError: uvicorn** | API wouldn’t start | Installed all required dependencies with `pip install -r requirements.txt` |
| **S3 access denied** | While syncing Knowledge Base | Ensured the IAM role had `AmazonS3ReadOnlyAccess` permission |
| **ValidationException** | CLI couldn’t run due to wrong placeholder | Replaced `your_model_arn` and `your_knowledge_base_id` with actual values |
